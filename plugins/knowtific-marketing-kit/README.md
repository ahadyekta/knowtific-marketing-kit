# knowtific-marketing-kit

A complete marketing toolkit for client projects. Ask any marketing question and the `marketing-coach` skill answers from a 16-file knowledge library plus the project's own `marketing/` folder. Commands cover setup and audits (`init`, `audit`), brand (`position`, `rebrand`, `design-brief`, `brand-world`, `customer-insights`, `copy`), content (`content-ideas`, `script`, `social-plan`), campaigns (`campaign-plan`, `creator-brief`, `partnerships`), ads (`ads-math`, `ad-concepts`, `ads-plan`), conversion (`funnel-build`, `lp-review`, `email-flows`, `sales-kit`, `outbound`), search (`seo-plan`) and narrative (`crisis`, `weekly-report`). Includes Australian compliance notes (Spam Act, SMS sender IDs, AHPRA, TGA, consumer law) and optional data connections (DataForSEO, Google Ads, GA4, Meta Ads, Klaviyo). Install: `/plugin marketplace add knowtific/knowtific-marketing-kit` then `/plugin install knowtific-marketing-kit@knowtific`. See the repository README for details.
